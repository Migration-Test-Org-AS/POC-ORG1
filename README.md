# POC-ORG1

This repository currently contains the foundation for the project: repository
ownership configuration, CI, and a README. It does not yet include an
application framework or business behavior.

## Smoke checks

The dependency-free smoke checks verify that the foundational files are
present and non-empty and that repository files do not contain unresolved
merge-conflict markers. Run them locally from any directory inside the
repository with:

```sh
bash scripts/smoke-checks.sh
```
